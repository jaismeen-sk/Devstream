      About the project

      A practical front-end portfolio project

      I built DevStream to make a growing course library easier to browse and keep track of. Search and category filters help learners find a course; the course dialog keeps extra details out of the way until they are needed; and the profile makes saved courses and progress easy to revisit. I built these interactions with semantic HTML, responsive CSS, and vanilla JavaScript, without a framework or backend.

      Course details load from courses.json. Enrollment, saved courses, and progress are demo experiences stored in this browser; lesson videos are embedded from YouTube. There is no backend or user account.
